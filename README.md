LegacyOS

A new legacy. A new operating system.

LegacyOS is an experimental operating system development project built with C, C++, Rust, and Assembly. Its goal is to explore low-level programming, operating system architecture, and the foundations of desktop computing.

---

About

LegacyOS is being developed as an independent operating system project, with a focus on understanding how operating systems work from the ground up.

The long-term vision is to create a functional desktop environment with its own interface, system components, and core utilities.

Technology Stack

Language| Purpose
C| Low-level system development
C++| Core system components
Rust| Experimental system modules
Assembly| Low-level architecture

Vision

LegacyOS aims to evolve into an operating system featuring:

- Custom desktop environment
- Graphical user interface (GUI)
- Window management
- File management
- System terminal
- Application launcher
- System settings
- Custom boot experience

Development Status

Status: Early Development

LegacyOS is currently an experimental project. Features and architecture are actively being developed.
