# LegacyOS

A standalone operating system developed by
RAVEN Technologies.

## About

LegacyOS is an experimental x86 operating system
built using C and C++.

## Technology

- C
- C++
- x86 architecture
- GRUB bootloader
- GCC
- GNU Make

## Features

- Custom kernel
- VGA text output
- C subsystem
- C++ kernel
- GRUB boot support
- Automated GitHub builds

## Build

Requirements:

- GCC
- G++
- GNU Make
- GRUB tools
- Xorriso

Run:

make

The ISO will be generated at:

build/LegacyOS.iso
